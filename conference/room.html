Everyone joins with the same private video link. The room is never recorded by NISMCAA.

Host controls

Host controls run inside the video call. The first person to join is the moderator:

  • Lobby (waiting room): Security (shield icon) → turn on Lobby, then admit or deny guests.
  • Mute everyone: Participants → Mute all.
  • Remove someone: Participants → ⋯ next to the name → Kick out.
  • Breakout rooms: Participants → Add breakout room.
  • Room password: Security → Add password.
